# 0.2.2 按边段组输入退线

目标是减少手动输入项，同时保持真实红线和已有退距准确。输入表格的组并不替换模型边线：每组保存完整原边索引，计算前依然传回每一条原边的退距。

## 使用
1. 读取选择后默认按边段组输入。同一直线、连续顺滑曲线自动分组；显著转角、曲率正负转换、直线/曲线转换及退距变化作为分组断点。
2. 预览按组着色，表格显示组号、原边范围和累计原边长度。输入一次退距，会应用到该组全部原边。
3. 点击预览线段或组号，或勾选表格，可选中组。勾选沿红线相邻的多个组，点“合并所选相邻组”。跨原边末尾与首尾的相邻组也可合并。
4. 不相邻的组禁止合并，以免误改另一条边界。合并不同退距不会自动覆盖原值；输入框显示“多值”，填写后才统一该组。
5. 点“所选拆为单边”或切换“逐边编辑”，可调整局部边。返回按组编辑时保留已有分组和参数。
6. “较细 / 标准 / 更多合并”加“重新自动分组”控制连续曲线归并程度。已有不同退距仍保留为断点。批量统一退线功能继续可用。

## 限制和验证
- 分组只辅助输入，不能推断道路侧、邻地侧等规划含义；生成之前仍需要核对组的覆盖范围。
- 默认以小于 25 度的连续转向作顺滑曲线候选，较细为 15 度、更多合并为 45 度。不是对原红线做 RDP 或移动顶点，不引入简化坐标误差。
- 自动分组后的项数取决于真实几何和退距变化；不能承诺截图 168 条边必然变成固定数量。
- 测试覆盖 168 段圆形归为 1 项、168 段四边形归为 4 项、环首尾合并、不同退距保留、输入应用到组内全部原边及完整 UI 生成参数传递。
- 逐边不同退距仍使用旧保守圆角内核；复杂输入的生成限制与带孔体量限制不因分组而改变。
