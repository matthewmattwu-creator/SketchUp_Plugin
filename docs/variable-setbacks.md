# 0.2.3 道路侧与邻地侧分组退距
- 每组可标记“道路侧”“邻地侧”“其他”。用途不决定退距，请按项目规划条件输入；重新自动分组保留用途和退距的变化断点。
- 各组退距展开到每条原始边；同退距的连续原边形成链，以该链自己的退距构建禁止建造区域。与用地多边形做差，可生成分裂后的多个独立体量。
- 每段的最短距离约束包括端点；不同退距交界及凹角采用圆弧过渡，不把整块地退距统一扩大成最大值。零退距边不添加缓冲区。
- 全部退距相同时沿用 0.2.2 尖角平行偏移；不同退距使用最短距离圆角规则。两者转角规则不同，人工对照时须使用相同规则。
- 曲线近似弦误差目标为 0.05 mm，向禁止区域外侧补偿 0.1 mm，保证退距不因内接弦减少；补偿是退距数值的增量，不是整体轮廓最大偏差保证；极窄区域的拓扑可能受补偿影响。输入红线坐标不改变。
- Ruby 再次按所有原始边及各自退距检查结果，未通过即取消该地块。道路/邻地用途按原边保存到生成体量参数。
- 带内孔地块仍不生成，超出计算资源或 SketchUp 极短边能力时明确失败。本版本未在用户的真实 SKP 或所有目标桌面版本上验收。
- 回归覆盖不同侧退距矩形及反向编号、2400 段矩形、2190 段合成螺旋道路 8 m / 邻地 3 m、凹 L 地块、零退距侧、共线退距变化、窄颈分裂、超大退距消失；JS 输出全部交由 Ruby 独立检查。
