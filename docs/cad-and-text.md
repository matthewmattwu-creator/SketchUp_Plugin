# 0.2.4 CAD 导入与规划条件粘贴识别

## CAD 文件框
插件在无选择时也可打开。点“导入 CAD 文件…”选择 DWG/DXF；图纸通过 SketchUp 自带 CAD 导入器作为独立组件导入，保留原点，避免与现有散线合并。文件不会上传。
导入后显示文件名及包围框米尺寸。单位由原生导入器处理，插件不向 DWG 导入器传未文档化的 units 参数；请用已知边长核对比例。选择红线所在图层后点“识别所选红线图层”。图层匹配是明确选择，不按颜色猜地块。
如果一个图层仍含多种线、开口或相交，沿用边界诊断；生成前再次核对同一 CAD 实例、图层、原点变换及红线签名，选择或几何改变后须重新读取。
原生导入及摆放可能分别占用撤销步骤；取消选择不改变已读地块。CAD 版本、许可和真实文件兼容性仍须在目标 SketchUp 桌面版验证。

依据：[DefinitionList#import](https://ruby.sketchup.com/Sketchup/DefinitionList.html#import-instance_method)、[Importer Options](https://ruby.sketchup.com/file.importer_options.html)、[UI.openpanel](https://ruby.sketchup.com/UI.html#openpanel-class_method)。使用的 DefinitionList#import 自 SketchUp 2021.1 提供，覆盖插件目标 API 范围。

## 像地址识别一样粘贴条件
粘贴后自动提取，或点“识别粘贴内容”重新解析。支持限高/建筑高度、层高、退线/退距/退让/退道路红线，米/m、厘米/cm、毫米/mm，全角数字及常见中文数字。

例如：限高36米；道路侧退线8米；邻地侧退线3米；组2退线5米；层高3.6米。

识别结果显示字段、米制数值、应用位置、原文依据，可勾选后“应用到当前地块”。道路侧/邻地侧默认匹配已标记原边，也可指定某个组；指定道路或邻地条件到组时同时设置用途标记。还可应用到当前勾选边段或指定原边。文本中的地块范围几何不会凭空推测，红线仍由 CAD / 当前选择读取。

范围、重复冲突、非法数值、缺失单位及不能对应的方位给出提示。存在不匹配边段或相互冲突的所勾选退距时，整次应用不改变任何参数。统一退距作为默认值，具体边段条件在其上覆盖；两个具体条件给同一原边不同值时拒绝应用。修改原文、切换地块或重分组后，识别预览失效，需要重新识别。

目前是本地规则式纯文本识别，不解析图片/PDF 的文字，也不会将自然语言当作坐标或直接生成 CAD 红线。复杂附加条件不会自动转换为插件尚不支持的约束；需人工核对。
