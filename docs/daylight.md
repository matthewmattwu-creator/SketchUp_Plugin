# 独立日照估算模块（未实现）

核心插件先单独交付。冬至日日照模块另行定义范围、开发及计费；此文档不代表该功能已提供。

必要输入：
- 项目经纬度、年份/冬至日期、模型北向、时区或真太阳时口径；
- 完整周边建筑和自身遮挡模型；
- 接收点，例如窗中心、窗台或指定立面采样点；
- 评估时间段、采样步长和累计/连续日照规则。

建议实现：
1. 根据位置与时间计算太阳方向；
2. 从接收点发射指向太阳的射线，检测模型遮挡；
3. 用分段采样累计可见直射日照时数；
4. 输出点位时数、颜色分布、步长、时间口径和场景范围。

需专门验证太阳方向、模型北向、模型单位、接收点偏移、防止自相交、透明/隐藏构件口径和累计误差。先用无遮挡及简单遮挡样例核对，再与可靠参考结果比较。

定位为前期估算，不输出正式审批合格结论。达到正式分析所需的标准、计算口径与认证应另行约定。
