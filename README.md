# SketchUp 可建体量快速生成

面向 **SketchUp 2023 及以上桌面版**的 Ruby 扩展。仓库初始描述：sketchup小插件_体量生成。

当前版本 **0.1.3 预览版**：逐边退线、限高包络、可建占地和满铺楼层建筑面积估算、多地块批量处理。日照模块尚未实现。几何自动测试与 RBZ 打包由 GitHub Actions 执行；SketchUp 内操作验收需要在实际桌面环境完成。

## 获取安装包

1. 打开仓库 **Actions → Geometry checks and RBZ**。
2. 选择开发分支最新一次成功运行，在 Artifacts 下载 `buildable-envelope-rbz`。
3. 解压下载的 ZIP，取得 `buildable-envelope-0.1.3.rbz`。
4. SketchUp **扩展程序管理器 → 安装扩展程序**，选择该 RBZ。
5. 菜单 **扩展程序 → 可建体量快速生成…**。

这是未签名的开发扩展。若当前加载策略阻止未签名扩展，应根据自己的工作环境决定是否允许加载本扩展。

也可本地打包：`python scripts/package.py`。输出位于 `dist/`。不要把整个仓库压成 RBZ；插件加载文件必须位于安装包根目录。

## 使用流程

- CAD 红线先通过 SketchUp 导入。插件读取模型内的面或线，不直接解析 DWG/DXF。
- 在模型根层级选中一个或多个水平地块面、完整闭合线，或包含红线的组/组件。嵌套组的变换会换算到模型坐标。
- 打开插件，查看原红线和边号。默认统一退线 5 米、限高 36 米、层高 3.6 米。
- 设置统一参数并应用到全部地块，也可切换地块分别修改各边退线、限高、层高和名称。
- 点击批量生成。完成提示逐地块列出成功、无可建范围或失败原因。
- 每个结果是独立组，包含限高体量、面积文字及隐藏的可建范围面。新一轮生成新增组，便于保留方案；一次撤销恢复本轮操作。

改变原红线或当前选择后，必须点击“重新读取当前选择”。输入红线不被删除或替换。

## 退线口径（使用前务必确认）

本版本按点到**每条有限边段的最短距离**限制可建范围，扣除边段的缓冲区，因此支持凹形地块、逐边不同距离和退线后分裂。

边段端点采用圆角缓冲；相邻边距离不同时，顶点采用较大的相邻退线半径。这与道路方向上的无限直线退线、尖角平行偏移或地方规划转角规则可能不同，不能混用面积结果。正式工程如要求尖角、指定道路侧方向、不同角点规则，应先扩展并验证该规则。

圆弧用 64 边外包圆近似，保证不额外放宽退线。最大半径误差为 `退线 × (1/cos(π/64)-1)`，约 0.121%；5 米退线约 6.0 毫米。小边、极小区域可能被数值容差过滤。输出几何面积会再次与纯算法面积核对。

## 面积口径

- 可建占地面积 = 退线后所有区域面积之和。
- 估算层数 = floor(限高 / 输入层高)。
- 满铺估算建筑面积 = 可建占地面积 × 估算层数。
- 限高自红线标高竖直向上，不含单独的屋顶设备或其他高度扣除。
- 建筑面积是几何容量估算，未考虑容积率、建筑密度、实际楼板、停车、核心筒、消防或日照约束。
- 100 × 60 米矩形、四边退线 5 米、限高 36 米、层高 3.6 米：占地 4500 ㎡，10 层，估算建筑面积 45000 ㎡。

## 输入范围和限制

- 单批最多 50 地块，每个地块最多 5000 条边；复杂 CAD 应先简化。
- 支持直线段构成的无内孔水平多边形。曲线按 SketchUp 已有线段处理，不解析真实 CAD 圆弧。
- 组内扫描所有面及无面的闭合线。请选择专门的红线组，避免把建筑或其他绘图一起选入。
- 内孔面、闭合线嵌套/交叠、断线、分叉、自交、倾斜地块会报告错误。
- 不跨 CAD 缺口自动连线。若导入后坐标节点尚未合并，请先清理。
- 分别选入的重复/重叠地块目前不会跨组自动去重；用户须确保地块清单准确。
- 坡地、按边限高、容积率控制、自动方案优化和日照分析不在本次核心版中。
- 兼容目标为 2023+；纯 Ruby 测试不能代替每个 SketchUp 版本和系统的运行验证。

## 0.1.1 修复

先从计算分片重建并简化外轮廓，再为每个分离区域建立独立体量。底面、顶面、侧面显式封闭，不再逐片创建、合并后拉伸。增加边的双面连接检查、闭合实体及体积核对。输出组采用局部坐标，减少 CAD 大坐标误差。仍需在 SketchUp 桌面实际复测。

## 0.1.2 接口兼容修复

目标版本明确为 SketchUp 2023、2024、2025、2026 桌面版。闭合检查通过实际接口能力探测：在定义对象提供 manifold? 时使用定义接口，否则使用组对象的 manifold?，兼容 2023 至 2026.1。定义接口仅从 2026.2 起提供，不能直接按年份假定它存在。

依据：[ComponentDefinition API](https://ruby.sketchup.com/Sketchup/ComponentDefinition.html#manifold%3F-instance_method)、[Group API](https://ruby.sketchup.com/Sketchup/Group.html#manifold%3F-instance_method)。自动测试包含旧/新接口模拟回归，不代表已在各版 SketchUp 桌面实际验收。

## 0.1.3 高分段曲线地块

将输入上限提高到 5000 条边，并加速自交检查。超过 200 边时，计算用闭合边界在 10 毫米容差内自动简化；原始 CAD/SketchUp 红线保留，面板仍以原始边号设置距离。退线参数发生变化的顶点强制保留，防止合并不同边的设置。简化后退线附加 10 毫米向内安全裕量，抵消曲线折线近似，故面积是保守估算。无法简化的尖角、逐边密集参数变化仍按原边计算，极端复杂情况会明确拒绝。无需用户重画普通高分段弧线。

计算分片及轮廓中绝对面积不超过 1e-8 ㎡的浮点残片按统一容差忽略；真实内孔仍拒绝并提示面积。该容差远小于 SketchUp 常用建模尺度。
